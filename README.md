# Joey Dufourd – Personal Website  

This repository contains the source code for my personal website, showcasing my work in **Biology, Bioinformatics, Big Data, and Data Science**.  

[Access the website](https://joeydufourd.github.io/)

The site includes:  
- 🧪 **Research & Projects** — Key publications and open-source repositories (e.g., [TELS1](https://doi.org/10.1016/j.celrep.2025.116260), [Telomere Dynamics – Gillespie Simulation](https://github.com/joeydufourd/telomere-dynamics-gillespie))
- 🧠 **Technical Skills** — An overview of tools and frameworks I use for data-driven biology (Python, R, TensorFlow, CellProfiler…)
- ✍️ **Blog (Work in Progress)** — Notes, tutorials, and reflections at the crossroad of biology, computation, and visualization
- 🌐 **Professional Links** — CV, ORCID, LinkedIn, and contact information
